# 📊 Superstore Sales & Profit Analysis – Excel

## 📌 Project Overview

This is my first Data Analytics project, developed using Microsoft Excel with the Sample Superstore dataset.

The main objective of this project is to explore sales and profit data, perform data cleaning and transformation, and create interactive reports using Excel.

I built this project while learning practical Excel and Power Query concepts.

## 🎯 Project Objectives

- Understand and explore Superstore sales data.
- Clean and transform raw data using Power Query.
- Analyze sales and profit performance.
- Compare performance across different regions and categories.
- Identify month-wise profit trends.
- Create visual reports using PivotTables and PivotCharts.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- PivotTables
- PivotCharts
- Excel Charts
- Data Cleaning and Transformation

## 🔄 Data Cleaning & Transformation – Power Query

The following Power Query operations were practised:

- Importing data into Power Query.
- Changing data types.
- Removing duplicates and handling errors.
- Filtering and sorting records.
- Splitting and merging columns.
- Creating Conditional and Custom Columns.
- Grouping data using Group By.
- Merging Queries.
- Appending Queries.
- Pivoting and Unpivoting columns.
- Loading transformed data into Excel.
- Refreshing data.

## 📈 Analysis & Visualizations

The project includes:

1. **Regional Profit Analysis:** Comparing profit across different regions.
2. **Month-wise Profit Analysis:** Understanding monthly profit trends.
3. **Category Analysis:** Comparing performance across product categories.
4. **Interactive Reports:** Using PivotTables, PivotCharts and filters to explore the data.
